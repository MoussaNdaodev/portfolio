# Portfolio — Moussa Ndao

Portfolio personnel de **Moussa Ndao**, développeur Mobile Flutter & Full Stack.

Disponible sur : [moussandao.dev](https://moussandao.dev)

## Stack

- HTML5 / CSS3 (design system custom)
- JavaScript vanilla (animations, reveal au scroll, thème clair/sombre)
- Aucun framework — 100% statique, ultra-rapide

## Structure

```
portfolio/
├── index.html              # Page unique du portfolio
├── photo-moussa.jpg        # Photo de profil
├── CV_Moussa_Ndao.pdf      # CV téléchargeable
├── CNAME                   # Domaine personnalisé (moussandao.dev)
└── .nojekyll               # Sert le site en statique (pas de build Jekyll)
```

## Déploiement

Hébergé sur **GitHub Pages** avec domaine personnalisé.

1. Push sur la branche `main`
2. Settings → Pages → Source : `Deploy from a branch` → branche `main`, dossier `/ (root)`
3. Le fichier `CNAME` applique automatiquement le domaine personnalisé
